# Triton Strategies

Triton Strategies is an independent investment research initiative focused on
multi-strategy portfolio research, quantitative analysis, market intelligence,
and geopolitical strategy.

## Website

https://triton-strategies.com

## Project

Triton currently operates a simulated investment portfolio using approximately
$10M of notional capital.

No external investor capital is currently managed.

All portfolio figures and performance shown on the website are simulated and
illustrative.

## Structure

- `index.html` — Main website
- `contact.html` — Contact page
- `styles.css` — Website styling
- `script.js` — Website functionality
- `images/` — Website assets
- `CNAME` — Custom domain configuration

## Disclaimer

Triton Strategies currently operates as an investment research initiative and
does not manage external investor capital. Simulated or historical performance
is not indicative of future results.
